# **App Name**: RS Systems Portfolio

## Core Features:

- Portfolio Showcase: Display a list of completed projects with descriptions and technologies used.
- Service Ordering: Allow users to order services via a form that sends an email upon completion.
- Interactive Number Guessing Game: Allow users to guess a three digit number.
- AI-Powered Design Tool: Integrate a tool that generates personalized website layout suggestions based on the user's portfolio content, powered by generative AI. The AI will use information about completed projects and technologies to suggest layouts.

## Style Guidelines:

- Primary color: Forest green (#38A3A5), evoking growth and tech-savviness, yet avoiding a money-green cliché.
- Background color: Pale grayish-green (#F0F4F3), almost white but retaining the hue.
- Accent color: Muted teal (#498587) for interactive elements; harmonious contrast.
- Body and headline font: 'PT Sans', a humanist sans-serif that combines a modern look and a little warmth or personality; suitable for headlines or body text
- Code font: 'Source Code Pro' for displaying code snippets.
- Use simple, professional icons that align with a tech/infrastructure aesthetic.
- Maintain a clean and organized layout with clear sections.
- Use subtle transitions and animations to enhance user experience.
